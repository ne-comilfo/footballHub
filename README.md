# Football Hub ⚽

Современное веб-приложение для просмотра информации о футбольных командах, игроках и турнирах.

## О проекте

Football Hub — pet-проект, созданный для изучения современных подходов к frontend-разработке. Приложение позволяет получать актуальную информацию о футбольных командах, игроках, матчах и соревнованиях, используя внешние REST API.

Проект разрабатывается с акцентом на качество архитектуры, производительность и удобство пользовательского интерфейса.

## Возможности

- просмотр информации о командах;
- просмотр информации об игроках;
- просмотр турниров;
- поиск;
- фильтрация данных;
- адаптивный интерфейс;
- темная и светлая темы;
- кэширование серверных данных;
- работа с URL-параметрами;
- обработка состояний загрузки и ошибок.

В настоящий момент приложение использует внешние REST API для получения информации о футболе.

## Запуск проекта

```bash
git clone https://github.com/ne-comilfo/footballHub.git

cd football-hub

npm install

npm run dev
```

После запуска приложение будет доступно по адресу:

```
http://localhost:3000
```
